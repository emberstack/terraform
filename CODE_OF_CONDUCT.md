# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be respectful, assume good faith, and keep the discussion on the technical
question. Disagreement about an approach is welcome and useful — contempt for the person proposing it
is not. Harassment of any kind is not acceptable, in issues, pull requests, or reviews.

## Reporting

For anything you would rather not raise in public, use
[GitHub's abuse reporting](https://github.com/contact/report-abuse). Maintainers can also be reached
by opening an issue for matters that are not sensitive.
